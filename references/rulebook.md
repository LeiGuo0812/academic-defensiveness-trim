# 防御性写作规则手册

本手册用于解决编辑时的一个分歧：一句话读起来很谨慎，究竟是多余，还是不说就会让读者误解？先读它前后的判断，找出作者研究了什么、依据是什么、希望读者据此相信什么。再试着删掉这句话，具体写出删前与删后允许作出的两种解释。如果两种解释没有区别，多半可以精简；如果改变了观察对象、比较、估计的精度或命题成立条件，就保留这部分信息。

下表可以直接跳到相应规则。短例均为自拟教学材料，不是可引用的研究结果。判例的完整语境见[编辑判例](decisions.md)，规则的上游出处见[来源记录](sources.md)。

## R01　把给假想审稿人的答辩还原为研究事实

**辨认：** 作者先写“有人可能质疑……”“为免被误以为……”，再用一段话解释自己的用意。先找出拿掉这段铺垫后还剩哪项信息。若只剩“作者已考虑周全”，可以整句删除。若剩下一项材料选择或方法事实，直接陈述它与问题的关系，不代替读者猜测异议。

**最小改法：** “为免读者以为两组因为观察时段不同而不可比，需要澄清，我们对两组均使用出院后30天的观察窗。”可改为“两组的观察窗均为出院后30天。”它交代了一个相同条件，并不承诺两组在其他方面可比。若文章专门检验“差异是否来自观察时段”的替代解释，保留这个问题及检验结果；那是论证。是否有真实审稿问题，另见 [R10](#r10)。

<a id="r02"></a>
## R02　区分“我们无意声称”和有信息的否定

“我们无意推断任何临床意义”主要描述作者态度。读者若只需知道随访测了什么，可写“随访记录了预约出席情况”。若上下文正在将出席率解释为症状改善，还需补上“未测量症状变化”。前者说清研究范围，后者指出两种构念不能替代；此时不能为了去掉否定句而删去后者。

注意三个不同的断言：“报告未给出该结局”说明材料内容；“研究未测量该结局”说明研究过程；“未观察到该结局”说明观察结果。只能写材料支持的那个。反例、未满足的条件、未能确定的效应方向、事先规定的排除项，也可能就是读者要找的答案。判断其是否防御，要看它排除了什么误读，而不是找“不”“未”“不能”等字。

<a id="r03"></a>
## R03　合并重复的保留语气，分开独立的证据限定

试着给每个限定各写一个理由。“也许在某种程度上可能提示”若只表达“这是一个解释”，保留一个与证据相称的动词即可；如果句子报告的是直接计数，可能一个缓冲词都不需要。反之，“探索性分析”“自报指标”“内部验证”分别说明分析的目的、测量如何取得、表现在哪里验证。探索性目的与事后决定不是同一件事；是否预先指定，按实际记录另行表述。它们不能因为都让结论变窄而互相代替。

**英文短例：** “In the exploratory analysis, the difference may possibly suggest a task-order effect.” 若顺序本身未被操纵，且已有材料支持将它作为一种解释，可写 “In this exploratory analysis, task order is one possible explanation for the difference.” 这一改法保留了探索性和解释的不确定性。若作者没有给出考虑顺序的理由，写清观察到的差异即可，不主动发明一个“可能”的原因。

<a id="r04"></a>
## R04　如实写不理想的结果，不替缺失的证据找理由

出现“未达显著，但这很可能因为……”“考虑到任务难度，这个结果仍很可喜”时，先分离三项信息：实际结果、作者提供的原因证据、作者的价值判断。把结果写清；若有检验原因的分析，写出它支持到什么程度。仅有小样本、复杂任务或噪声的可能性，不足以认定它们造成了阴性结果。若区间显示估计不精确，可以说明不精确；不要把非显著改成“两组等效”，也不要将点估计的方向改成“有改善趋势”。

**对照：** 若同一估计的区间同时包含无差异和作者预先界定的实质差异，应保留这个解释边界。“两种方案效果相同”比原结果走得更远。若确实完成预设等效性检验并达到其判定标准，可以报告等效结论及界值。没有做某项重要比较时，交代比较缺失限制了哪个判断；不要替作者补写“由于资源有限”，也不要编造新实验来消除局限。

<a id="r05"></a>
## R05　把“公平、稳健、验证充分”换成实际比较条件

把评价词暂时遮住，查看能否指出相同的条件、改变的条件及相应结果。“为确保公平，两种模型都使用相同的划分”可改为“两种模型使用相同的训练集与测试集”。这句话不证明样本代表性或人口亚组公平；如果公平性本身是研究对象，反而要保留作者对指标、亚组及比较方式的定义。

对“稳健”也做同样检查。如果作者只在另一阈值下重算一次且方向未变，可写“采用另一阈值时，估计方向未改变”。不能据此声称对数据来源、模型设定与人群变化均稳健。如果稿件给出独立验证、评价指标与失败情形，就不必削弱这些实质性证据；把“充分验证”改成读者能用来作判断的信息。

<a id="r06"></a>
## R06　界定实际贡献，不用防御或宣传来证明新颖性

“并非简单地套用了某方法”“即使不是第一项，也无损其重要性”都容易让方法差异消失。改前先问：相对哪一项已有工作，本文改变了什么对象、条件、数据或推导？这些变化回答了什么原来没有直接回答的问题？材料支持哪一点就写哪一点；若提供了原始参照，引文应随比较保留。

例如，文章确实在另一人群中独立重复过一项分析，可将“这是第一次全面验证了该理论”改为“我们在另一人群中重复检验了原研究报告的关联”。不要把重复验证降格为“仅仅是一次初步尝试”。若作者确有检索范围和依据，“在所检索的文献中未发现……”可以保留，不能改成“此前从未有人研究”。在申请书中，可以清楚写拟解决的问题及理由；预期贡献不能改写为已取得的发现。

<a id="r07"></a>
## R07　修正主张本身：核对测量、比较、因果及外推

给每个重要结论找出与之对应的测量或对比。危险的情况常不是动词过强，而是句子的主语、结局或比较对象已经换了。此时把“证明”换成“似乎提示”仍然保留原错误。

| 原材料 | 可以报告 | 不能自行升级为 |
| --- | --- | --- |
| 记录的是转诊意愿 | 参与者报告的意愿 | 实际接受了转诊、病情改善 |
| 只给出各组自己的前后检验 | 两组各自的变化；若与主张有关，指出未提供变化量的组间比较 | 一组显著另一组不显著，因此干预优于对照 |
| 同次观察记录两项指标 | 该样本中两项指标的关联 | 一项先于另一项、可导致或逆转另一项 |
| 名单来自单一门诊 | 该门诊样本中的观察 | 所有患者的症状分布或其他机构的服务效果 |
| 在既有数据中回顾性预测结局 | 在该数据和验证设计下的预测表现 | 指导决策能改善临床结局 |

反向也要检查：存在预设的组间对比、明确的识别条件或经检验的理论命题时，不应一律改写为“观察到关联”。依据设计、实际比较及其成立条件选择动词；不能仅凭“干预研究”四个字，替作者确认所有分析都支持因果解释。

<a id="r08"></a>
## R08　以读者在哪里会误解，决定限制写在哪里

把限制移向局限段落前，想象只阅读原位置的读者。一个图中只有完成随访的人进入分母，就在图注或图中交代；不能要求读者先翻到全文最后才知道百分比表示谁。若相邻三个讨论段只是解释同一组横断面关联，且都没有重新暗示时间顺序，可在相关解释第一次出现时界定，再合并重复段尾。若后段提出了新的机制解释，则需单独审视它是否有依据。

摘要、正文、图注常被分开阅读。有意重复决定结论的样本、时间尺度或分析范围，并不等于冗余。对于全局问题，则尽量具体交代它影响哪一类判断。例如“所有报告均来自同一登记系统”比每段都补“推广时应谨慎”更有用。看不到全文时，不声称“已在讨论交代”；只能在可见文本中移位，或标出建议位置供作者判断。

<a id="r09"></a>
## R09　去掉空泛的段尾评价后，补足有依据的讨论

“这些结果应谨慎解读，但仍提供了重要启示”同时具备谦抑和肯定的口气，却没有说明发现改变了什么认识。先删去它，看看此前是否已经完成解释。已完成就停；若段落只复述数字，追问哪种人群、场景、条件或概念之间的区别能由这些结果说明，再查原稿有无相应材料。不必每段都交一份“结果、意义、局限、展望”清单。

**短例：** 当材料只表明有的论文同时测量两种指标，但未检验个体层面的对应关系，可以写：“这些论文可以说明两类指标已被纳入同一设计；要判断其中一项指标较高的受试者是否在另一项上也较高，还需要用每位受试者的两项测量值分析关联。”这里解释了已有文献究竟积累了哪类证据。若已报告个体关联，不能仍机械地套用这句。若没有依据提出具体解释或展望，宁可止于有根据的判断。

<a id="r10"></a>
## R10　真实质疑、方案偏离和伦理披露应直接回答

审稿回复的读者明确提出了问题，直接说“没有”有时是最有效的信息。例如，审稿人问是否预先指定一个切点，若材料明确是事后选取，回信应直接答“没有，该切点为事后选取”。正文宜在使用它的方法或解释旁写明身份，不必将整段回复移入论文。若修订尚未完成，不把“将补充”改成“已补充”；没有实际页码、行号或新增分析，不代填。

盲法、注册、分析集、方案偏离、受试者保护、利益冲突及期刊要求的披露等，要按实际记录报告。句子语气再像声明也不能删除必要内容。若材料只给出“原定三次随访，实际进行了两次”，应保留原计划与实际执行的区别；原因不详就向作者核对，不补写伦理理由、批准编号或未提供的解释。

<a id="r11"></a>
## R11　保留定性、理论和方法研究中的有效异议

“另一种解释是……”“除非……否则……”在某些研究里是主要论证。定性研究可借不符合主主题的材料界定主题适用于哪些情境；若把那段经历当作“负面结果”删掉，读者便无从判断解释的边界。理论文章的反例检验命题是否成立；方法研究的失效条件说明何时不宜使用。不要将这些内容统一移入局限段，更不要用“可能”把一个必要前提改成可有可无的考虑。

判断时找异议与前文的关系。若它指出具体材料、竞争解释、证明中用到的前提或反例，就让作者把逻辑写完。若只写“我们的解释并不完美”，且没有说明另一种解读是什么，可以删除。定性材料不强制转换为频率；证明不要求逐句配数字；方法的适用条件应使用原有术语、符号与定义。

<a id="r12"></a>
## R12　原稿相互矛盾时分开交付事实与疑问

去掉辩护句后，最后读一次数字、计量单位、分母、方向、时间点、预设或探索性身份及引文。数字一致不代表含义一致：“百分比”有分母；“百分点”表示两个百分数之差。同一引文不能在合句后看似同时支持新加入的因果解释。方向、数字、来源或引文对应关系有冲突时，不因摘要更醒目或表格更详细就默认某一处正确。

**处理示例：** “正文称32例完成随访，表注写30例。”暂不在结果中写完成率；在作者问题中标明两处位置，并问“这里是否为不同分析集？请确认该比例使用的分母”。对不依赖争议数字的句子照常修改。如果作者要求只读审校，给出定位与冲突即可；如果只要干净正文，在交付格式允许时单列待核实信息，不把猜测藏进正文。

实际交付时，规则编号供定位和讨论使用。可以只回一句无需修改，或者只给完整改稿；无需让读者看到全部判断过程。
